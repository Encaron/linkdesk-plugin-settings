## 一、这一轴是什么

壳把「哪类文件默认由哪只插件打开」的**声明面**做出来之后，**消费面（看与改）**住本插件：设置页新增一整组「**默认打开方式**」，一个地方看全、也能就地改。本插件不判定任何打开语义——**判定归壳**（宿主解析纯函数 ＋ 覆盖表 `workbench.fileAssociations` 是唯一真相源），本仓只**呈现 ＋ 写用户覆盖**。

## 五、验收时的夹具纪律（复现须知）
